## 🧩 本仓库自带什么

- **一键体检**：每周 GitHub Actions 巡检所有下属仓库的存活状态（见 [.github/workflows/weekly-check.yml](.github/workflows/weekly-check.yml)）；
- **健康总览**：[docs/index.html](docs/index.html) 把六个模块的链接、更新时间、状态汇总成一页；
- **结构数据**：[data/modules.json](data/modules.json) 机器可读，可被你自己的脚本消费。
