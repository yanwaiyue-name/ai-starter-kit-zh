## What this is

You already have four scattered original repos, each covering one stage:

| Repo | Stage |
| --- | --- |
| [xiaobai-to-dalao](https://github.com/yanwaiyue-name/xiaobai-to-dalao) | Beginner environment: proxy + software setup (Windows-first) |
| [agent-download](https://github.com/yanwaiyue-name/agent-download) | Tools: 47 AI clients, official links + SHA256 |
| [airport-nav](https://github.com/yanwaiyue-name/airport-nav) | Network: airport nav + weekly health-check |
| [students-howtolivebetter](https://github.com/yanwaiyue-name/students-howtolivebetter) | Decisions: student life guide (evidence-graded) |

This repo is the **funnel entry**: walk the route below and you go from "knows nothing" to "can tinker with agents / side hustles / jailbreaks". It only indexes and chains — the real content lives in those four repos (plus the two new ones, [ai-agent-hub-zh](https://github.com/yanwaiyue-name/ai-agent-hub-zh) and [ai-sidehustle-zh](https://github.com/yanwaiyue-name/ai-sidehustle-zh)).

## What this repo ships

- **One-click health-check**: weekly GitHub Actions audits all sub-repos (see [.github/workflows/weekly-check.yml](.github/workflows/weekly-check.yml)).
- **Health overview**: [docs/index.html](docs/index.html) rolls up six modules' links, update times, and status.
- **Structured data**: [data/modules.json](data/modules.json), machine-readable.
